# **App Name**: GuardianAI

## Core Features:

- Educational Content: Informational pages detailing how AI can be used to combat human trafficking, including case studies, resources, and contact information for relevant organizations.
- AI Support Chatbot: An AI-powered chatbot that serves as a tool to provide immediate support, information, and resources to potential victims or individuals seeking help related to human trafficking. The chatbot can answer questions, provide guidance, and connect users with relevant organizations.
- Resources and Reporting: A contact form and directory of organizations, including hotline numbers and website links.
- Home Page: Home Page (Hero Section) with title "AI for Combatting Human Trafficking", tagline "Leveraging Technology for a Safer Tomorrow", and a short intro (3–4 lines) explaining what the project does.
- Problem Overview: Problem Overview with stats about human trafficking globally and in India.  Reasons why human trafficking is hard to detect.  Explanation of why AI can help.
- Our AI Solution: Explanation of how the AI works: detecting patterns, suspicious activities, etc. Technologies used: (e.g., Machine Learning, Natural Language Processing, Image Recognition, etc.)
- Impact Section: Impact Section: How this project will make a real-world difference. Example: "Helps NGOs, Law Enforcement, and Communities."
- About the Brains Behind It: About the Brains Behind It (Team Section): A dedicated section called "Brains Behind the Initiative." with "Meet the Innovators.  This project is envisioned and built by Aditya Bhatia and Mahin Mirza, Computer Science students at KR Mangalam University, driven by a passion to make the world safer using AI."
- Call to Action: Call to Action: "Join us" / "Learn More" / "Support the Mission" — linking to NGOs or more reading resources.
- Contact Section: Contact Section: Simple form: Name, Email, Message.

## Style Guidelines:

- Primary color: Teal (#008080) to convey trust and stability.
- Secondary color: Light gray (#F0F0F0) for clean content backgrounds.
- Accent: Blue (#4682B4) for interactive elements and calls to action.
- Clean and professional typography for easy readability and accessibility.
- Use clear and recognizable icons to represent different sections and resources.
- A clean, intuitive, and responsive layout that is easy to navigate on all devices.
- Brains Behind Creatively:  Instead of just writing names normally, you can use animated cards or hover effects. Two profile cards side-by-side.  On hover, it can show a short description about each person ("Computer Science Student passionate about AI for Social Good.") Or create a timeline style showing: 2025: Project initiated by Aditya and Mahin -> Built using AI models -> Real-world testing started -> etc.

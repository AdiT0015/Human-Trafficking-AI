# Combatting Human Trafficking Using Innovative AI Solutions

This project aims to leverage Artificial Intelligence (AI) to combat human trafficking by providing an interactive web platform and an integrated chatbot. The platform raises awareness, educates the public, and offers real-time assistance through a responsive AI-driven chatbot.

## 📄 Project Overview

The platform includes:
- An informative website with resources, news, and statistics related to human trafficking.
- A smart chatbot capable of answering questions, sharing emergency contacts, and offering helpful tips.
- Real-time user interaction logging and analytics for impact evaluation.
